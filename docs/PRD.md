# Jangs 리빙 스마트스토어 홍보 사이트 MVP PRD

## 핵심 정보

**목적**: Notion CMS 기반으로 네이버 스마트스토어 'Jangs 리빙'의 상품을 카테고리별 Dashboard 형태로 홍보하고, 방문자를 스마트스토어 구매 페이지로 유도하는 웹사이트
**사용자**: Jangs 리빙 생활용품에 관심 있는 일반 소비자 및 잠재 고객

## 사용자 여정

```
1. 홈 페이지 (Dashboard)
   ↓ 카테고리 클릭 또는 검색어 입력

   [카테고리 클릭] → 2. 카테고리 페이지
   [검색어 입력]   → 2. 검색 결과 (카테고리 페이지 내 필터링)
   ↓ 상품 카드 클릭

3. 상품 상세 페이지
   ↓ "네이버에서 구매하기" 버튼 클릭

4. 네이버 스마트스토어 상품 페이지 (외부 이동)
```

## 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | 상품 목록 조회 | Notion DB에서 상품 데이터를 가져와 카드 형태로 표시 | 서비스의 핵심 가치 | 홈 페이지, 카테고리 페이지 |
| **F002** | 카테고리별 필터링 | 8개 카테고리(가구/인테리어, 생활/건강, 패션잡화, 화장품/미용, 디지털/가전, 출산/육아, 스포츠/레저, 패션의류)별 상품 분류 | 3,344개 상품의 효율적 탐색 | 홈 페이지, 카테고리 페이지 |
| **F003** | 상품 상세 조회 | 상품의 이미지, 가격, 할인율, 설명 등 상세 정보 표시 | 구매 결정 지원 | 상품 상세 페이지 |

| **F005** | 상품 검색 | 상품명 기반 키워드 검색 | 빠른 상품 탐색 | 홈 페이지, 카테고리 페이지 |

## 페이지별 상세 기능

### 홈 페이지 (Dashboard)

> **구현 기능:** `F001`, `F002`, `F005`, `F008` | **메뉴 위치:** 메인 랜딩

| 항목 | 내용 |
|------|------|
| **역할** | Modern하면서 Simple한 Dashboard 형태의 상품 홍보 메인 페이지 |
| **진입 경로** | 사이트 접속 시 기본 랜딩 페이지 |
| **사용자 행동** | 카테고리별 인기 상품 둘러보기, 검색어 입력, 카테고리 선택 |
| **주요 기능** | - 히어로 배너 (Jangs 리빙 브랜드 소개)<br>- 카테고리 네비게이션 카드 (8개 카테고리 아이콘+이름)<br>- BEST/NEW 태그 상품 우선 노출 섹션<br>- 카테고리별 인기 상품 미리보기 (각 4~6개)<br>- **검색바** (상품명 키워드 검색)<br>- **"전체 보기"** 버튼 → 카테고리 페이지 이동 |
| **다음 이동** | 카테고리 클릭 → 카테고리 페이지, 상품 클릭 → 상품 상세 페이지, 검색 → 카테고리 페이지 (필터 적용) |

---

### 카테고리 페이지

> **구현 기능:** `F001`, `F002`, `F004`, `F005`, `F007`, `F008` | **메뉴 위치:** 카테고리 메뉴

| 항목 | 내용 |
|------|------|
| **역할** | 특정 카테고리의 상품을 그리드 형태로 나열하고 정렬/검색 제공 |
| **진입 경로** | 홈에서 카테고리 카드 클릭, 네비게이션 카테고리 메뉴 클릭, 검색 결과 |
| **사용자 행동** | 상품 목록 스크롤, 정렬 변경, 검색 필터링, 상품 카드 클릭 |
| **주요 기능** | - 카테고리 제목 및 상품 수 표시<br>- 상품 카드 그리드 (이미지, 상품명, 원가, 할인가, 할인율, 태그)<br>- 정렬 옵션 (최신순/가격 낮은순/가격 높은순/할인율순)<br>- BEST/NEW 태그 상품 상단 우선 노출<br>- **"네이버에서 구매"** 빠른 링크 (카드 내)<br>- **검색바** (카테고리 내 검색)<br>- 페이지네이션 또는 무한 스크롤 |
| **다음 이동** | 상품 클릭 → 상품 상세 페이지, 구매 버튼 → 네이버 스마트스토어 (외부) |

---

### 상품 상세 페이지

> **구현 기능:** `F003`, `F004` | **메뉴 위치:** 카테고리 페이지에서 진입

| 항목 | 내용 |
|------|------|
| **역할** | 개별 상품의 상세 정보를 보여주고 네이버 스마트스토어 구매로 유도 |
| **진입 경로** | 홈 또는 카테고리 페이지에서 상품 카드 클릭 |
| **사용자 행동** | 상품 이미지 확인, 가격/할인 정보 확인, 상세 설명 읽기, 구매 버튼 클릭 |
| **주요 기능** | - 상품 대표 이미지 (확대 뷰)<br>- 상품명, 카테고리, 태그 표시<br>- 가격 정보 (원가, 할인가, 할인율)<br>- 배송 정보 (배송비, 오늘출발 여부)<br>- 상품 상세 설명 (Notion 페이지 콘텐츠)<br>- **"네이버에서 구매하기"** CTA 버튼 (스마트스토어 링크)<br>- 같은 카테고리 추천 상품 |
| **다음 이동** | 구매 버튼 → 네이버 스마트스토어 상품 페이지 (새 탭), 뒤로가기 → 카테고리 페이지 |

## 기술 스택 (최신 버전)

### 프론트엔드 프레임워크

- **Next.js 15** (App Router + Turbopack) - React 풀스택 프레임워크
- **TypeScript 5** - 타입 안전성 보장
- **React 19** - UI 라이브러리

### 스타일링 & UI

- **TailwindCSS v4** - 유틸리티 CSS 프레임워크
- **shadcn/ui** (new-york style) - React 컴포넌트 라이브러리
- **Lucide React** - 아이콘 라이브러리

### CMS & 데이터

- **Notion API** (@notionhq/client) - Notion 데이터베이스 CMS 연동

### 배포 & 호스팅

- **Vercel** - Next.js 최적화 배포 플랫폼

### 패키지 관리

- **npm** - 의존성 관리
